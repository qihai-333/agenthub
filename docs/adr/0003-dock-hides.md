# 侧栏不常驻：滑出屏幕，留 3px 热区

侧栏在有应用显示时默认滑出屏幕，只在需要时出现。滑出状态窗口移到 `x = -89`，左边只留 3px 可见；鼠标碰到这 3px、或点任务栏图标，它就滑回来，并重放一次"堆叠散开"动画。

这条**推翻了**同一份 ADR 目录里更早的「侧栏固定展开」。当时的理由是"收起会改变内容区宽度、右侧画面会跳"。这个理由依然成立，所以新方案换了做法：不再改内容区宽度，而是让**应用窗口始终占满整屏**，侧栏滑出时直接盖在它左边 92px 上，滑走时也不重排。宽度变化的问题就从"每次收起都重排"变成了"根本不重排"。

代价是应用左边的 92px 在侧栏出现时会被盖住。判断这可以接受：侧栏出现的时刻就是你正在挑应用、不看内容的时刻。

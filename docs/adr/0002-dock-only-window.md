# 只占侧栏：程序窗口永不覆盖内容区

程序的窗口在任何时刻都只有侧栏那么宽（展开 92px、收起 6px），从不铺满屏幕。应用的真实窗口直接占据侧栏右侧，与我们的窗口在几何上不重叠。

这是为了消灭一整类故障：早先版本在接管应用时把窗口铺到全屏，再用真实的应用程序窗口盖住内容区。只要层叠顺序因为任何原因翻转（点击侧栏、Z 序抖动、焦点切换），用户看到的就是一块黑底，而应用窗口其实还在原位正常运行。把两个窗口的矩形做成不相交之后，层叠顺序不再影响任何可见结果。

代价是程序没有「全屏工作台」的形态：启动时不再有全屏开屏动画，闲置时露出的也是桌面而不是一块深色背景。这些都被判定为可接受的损失，因为「永远不黑屏」比「开屏好看」重要。

# 名额制：显式选入，取消即杀进程

同时最多三个应用处于已选状态，由用户显式选入与取消，程序不做自动淘汰。名额的判据是进程存活：取消一个应用会立即结束它的进程树并释放名额，进程自己退出则自动取消。

被否决的方案是「满了自动挤掉最久未用的那个」。理由：这个程序是日常入口，每次开第四个都让程序替你决定关谁，等于把风险决策自动化了——被挤掉的那个可能正带着没保存的草稿。把选择权交回用户，代价是偶尔要手动取消一次，换来的是任何时候都不会莫名其妙少一个应用。

这条决定的连锁后果是「取消必须等于杀进程」。如果取消只释放名额而保留进程，就会出现「界面说两个、内存里却四个」的假账，名额也就失去了它唯一的意义：控制资源。
